G96 or G97?

G96: constant Vc, rpm follows the diameter. For turning.

G97: fixed rpm. For approaches, live tools and before rapids.

With G96 you always need the G50 cap.

Polar interpolation

G12.1: X (diameter) and C behave like a mill's X and Y.

The spindle is stopped and acts as a C axis: M5 P11, M35, G28 H0.

End: G13.1.

Before Cycle Start

  • Chuck max rpm ≥ G50
  • ≥ 75 mm out of the jaws
  • Sub-spindle at home
  • T0202 and T0101 measured
  • Live tool stick-out ≥ 40 mm
  • Live tool rpm corrected
  • Single block, low override

Watch out!

During facing the rpm climbs by itself up to 5,000 as the tool reaches the centre.

It's not a machine fault: it's G96.
