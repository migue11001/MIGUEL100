Why so few rpm? The carriage moves 12 times faster than when turning and has to stop at Z-32.

Work cycle

  1. Safety: G50 S6000, retract X400 → Z400
  2. Tool: T010101, G95, M8, 500 rpm
  3. Approach: X39.79 Z12.5
  4. Threading: G71, all passes
  5. Retract: M9, X400 → Z400, M2

Always X before Z: leave the way you came in.

The 3 threading rules

  1. G95: advance one pitch per rev. A thread is a helix.
  2. G97: fixed rpm. If it changes, servo lag changes and passes don't land in the same groove.
  3. Run-up distance before the part (here 12.5 mm = 5 pitches).

The nut won't go on!

M20×2.5 external depth:
0.6134 × 2.5 = 1.534 mm

Programmed: 1 mm (H2.)

Nut: minor Ø = 20 − 1.0825 × 2.5 = Ø17.294
My root: Ø17.791, bigger, so it hits.

Fix: depth 1.534 → root ≈ Ø16.93

Other errors

  • M73 = constant depth: only ~2 passes and the second takes 3× as much. → use M75, 6–10 passes
  • No spring pass. → the tool deflects and leaves material
  • Radial infeed with a 2.5 pitch. → flank infeed at 29–30°
  • Both programs are called 1001 inside.

Depth ∝ √n, so every pass removes the same chip section.

Before pressing Start

  • X400 / Z400 within travel
  • Turret indexes freely
  • Nothing in front of the part (diagonal rapid)
  • Groove or clearance at Z-32
  • Part out of the jaws ≥ 40 mm
  • Single block + rapids at 25 %

Watch out!

During threading Feed Hold doesn't work. Only Reset or emergency stop.

Stopping the carriage with the spindle running would wreck the thread. That's why everything must be checked beforehand.
