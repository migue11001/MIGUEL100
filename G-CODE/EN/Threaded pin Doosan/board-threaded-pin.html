T0100?!

Last two digits = offset: 00 = none.

In the flange: T0202, T0101.

→ in Fusion “Compensation offset” = station number.

The nut won't go on!

P2 external depth: 0.6134 × 2 = 1.227

Programmed: 1.016 (Ø25.255 → Ø23.223)

Correct root ≈ Ø22.8. Same mistake as the M20 thread!

Other warnings

  • Groove Ø23.674: higher than the thread root
  • Profile to Z-54.14, part-off at Z-44.64
  • Groove: goes in and out in G1 from Ø71
  • Third program called 1001

Threading rules

  1. G99: F = pitch
  2. G97: fixed rpm
  3. 3–5 pitches to accelerate
  4. Groove deeper than the thread

Here only the first two are followed.
